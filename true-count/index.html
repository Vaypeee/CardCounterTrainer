True count: how to calculate it

The running count tells you which way the shoe leans. The true count tells you how much. It is the number you bet with and the number every index play is based on. Here is how to get it quickly and accurately at the table.

1Why the running count is not enough

A running count of +6 means six more small cards than big cards have left the shoe. With one deck left, those extra tens and aces are concentrated in 52 cards: a big advantage. With five decks left, the same surplus is spread over 260 cards and barely matters. The true count corrects for this by expressing the surplus per deck remaining.

2The formula

True count = running count ÷ decks remaining
Running count +9, about 3 decks left → +9 ÷ 3 = +3
Running count +9, about 4½ decks left → +9 ÷ 4.5 = +2

This applies to balanced counts such as Hi-Lo, Zen, Omega II and Halves. Unbalanced counts such as KO are built so that you can bet from the running count directly (see counting systems compared).

3Estimating the decks remaining

  • Look at the discard tray, not the shoe. The discards are stacked neatly and easier to judge. Decks remaining = decks in the game − decks in the tray.
  • Learn what one, two and three decks look like. At home, stack real decks and look at them from a seat’s distance. A deck is about 1.5–1.7 cm high.
  • Half-deck precision is enough in a six-deck game. Near the end of the shoe, be more careful: dividing by 1 or by 1.5 changes the result a lot.

4Rounding

The division rarely comes out even. The two common conventions are floor (always round down: +2.8 → +2, −1.2 → −2) and truncate (drop the decimals: −1.2 → −1). Most players use floor with the Hi-Lo indices. What matters most is to use the same convention as the index numbers you learned, every time. The trainer’s True Count mode lets you choose decks to the nearest half or whole deck, and floor, truncate or round.

7Practice until it is instant

  1. Learn the running count first: count a full deck down to 0 in under 25 seconds.
  2. Drill the division on its own with random running counts and deck amounts. The trainer’s True Count mode does exactly that, timed.
  3. Then combine both: deal a shoe, stop at random points, estimate the decks left and convert.

8FAQ

Do I need the true count in a single-deck game?

Yes, but it is simpler: with half a deck left, the true count is double the running count. Many single-deck players simply adjust by eye.

Should I divide by decks played or decks remaining?

Always by decks remaining. Dividing by decks played is a common beginner mistake and gives nonsense results early in the shoe.

How precise do I need to be?

An error of half a deck in the middle of a six-deck shoe rarely changes the integer true count. Errors near the end of the shoe do, so slow down there.
